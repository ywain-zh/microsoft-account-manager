## 本次更新内容摘要
- 新增 `/services/sub2api/codex-login` 管理页面和侧边栏入口。
- 新增 Codex Login 配置弹框，支持项目路径、邮箱、短信、代理、注册、Sentinel、超时和 HTTP 参数配置。
- 新增后端 `/api/sub2api/codex-login/config` 配置读写接口。
- 新增后端 `/api/sub2api/codex-login/run` 流式运行接口，通过 `uv run python main.py` 包装外部 CLI。
- Codex Login 运行日志使用 SSE 输出，并在后端对密码、API Key、token、手机号、邮箱和保存路径做脱敏。
- 第一版不读取或展示外部 CLI 生成的 `success/`、`fail/`、`tokens/`、`sentinel_cache.json` 敏感文件。
- 当前工作区还包含 779 卡相关旧文件删除和 CloudMailShareView 既有修改，本次按用户要求一并发布。

## 风险说明
- Codex Login 功能会在运行前写入外部项目 `config.json`，其中包含邮箱/SMS/代理等敏感配置。
- Codex Login 功能依赖 Node 后端启动 Python/uv 进程，若容器运行环境没有 `uv` 或无法访问外部项目路径，则真实任务无法运行。
- 外部 CLI 可能生成包含密码、token、cookie 的敏感文件；本次页面不展示这些文件。
- 工作区存在用户此前留下的 779 卡相关删除和 CloudMailShareView 修改，本次按“所有内容一起打包”要求一并发布。
