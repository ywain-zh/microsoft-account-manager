## 本次更新内容摘要
- 公益站“添加账号”新增普通公益站/宝可梦套餐类型选择，并增加宝可梦续费快捷入口。
- 新增宝可梦独立配置页，可维护多个邮箱密码账号、启用状态和一个加密保存的当月优惠码。
- 使用站点前端当前协议登录、校验优惠码、创建零元月付订单，并仅对已确认总额为零的订单执行站点页面同款零元结算，串行处理全部启用账号。
- 非零金额、待支付订单、无效优惠码和缺失字段均停止该账号；优惠券每人限用一次时记为跳过。
- 后台任务、运行日志和账号结果持久化保存，页面可轮询进度并在刷新后恢复任务视图。
- 汇总成功、跳过和失败数量，并保存续费前后到期时间；密码、Token、优惠码和原始响应不进入日志。

## 风险说明
- 续费适配基于 `web1.52pokemon.cc` 当前公开前端协议、固定套餐 ID `8` 和月付周期 `month_price`；站点修改 API 地址、响应编码或字段时需同步更新。
- 零元订单必须调用站点页面同样使用的零元结算步骤；实现会先再次确认订单详情金额为零，任何非零订单均不会结算。
- 仅低频串行请求，不使用 `curl_cffi`、TLS 指纹伪装或其他反检测绕过。
- 首次线上真实续费需由管理员录入账号和当月优惠码后手动触发。
