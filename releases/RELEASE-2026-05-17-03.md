## 本次更新内容摘要
- 删除 `/services/sub2api/codex-login` 前端路由和侧边栏入口。
- 删除 `Sub2ApiCodexLoginView.vue` 页面和 `sub2api-codex-login.ts` 状态模块。
- 删除前端 Codex Login 类型和 API 客户端方法。
- 删除后端 `/api/sub2api/codex-login/config` 和 `/api/sub2api/codex-login/run` 接口。
- 删除后端外部 Python CLI 启动、配置写入、进程终止和日志脱敏相关代码。
- 保留现有 Sub2API 检测、Cloud Mail、微软邮箱和系统设置功能。
