## 本次更新内容摘要
- 前端在翻译 HTML 邮件前判断邮件复杂度：体积较大或 HTML 标记比例过高时，改为发送提取后的纯文本正文。
- 后端增加 HTML 翻译保护阈值：大型 HTML、片段过多或占位文本膨胀过多时，自动降级为纯文本翻译。
- 保留小型简单 HTML 邮件的格式翻译能力，减少对普通短邮件体验的影响。
