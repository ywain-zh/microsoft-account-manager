## 本次更新内容摘要
- 长链后端从 Playwright request 改为 TS 调 Python helper，通过 stdin/stdout 传 JSON，避免 token 暴露在命令行。
- Python helper 使用 `curl_cffi>=0.14.0` 和 `impersonate="chrome136"` 执行 ChatGPT checkout、代理检测、GoPay Stripe/Midtrans 跳转提取。
- API 请求支持 `linkType`、`checkoutUiMode` 和 GoPay 账单字段；旧请求默认仍按 hosted 长链处理。
- 前端新增 Hosted / GoPay 链类型选择、GoPay 账单资料、复制 Session 地址、多链接结果展示。
- Docker 运行镜像新增 Python venv 和 `curl_cffi` 安装，服务器仍只执行固定 tag 镜像 pull/up。
- 构建流程新增 runtime asset 复制，确保 helper 进入 `build/server/runtime`。
