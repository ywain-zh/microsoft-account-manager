## 本次更新内容摘要
- Cloud Mail 配置信息弹框改用浏览器不易触发密码管理器的字段命名与 `autocomplete` 设置，避免打开弹框时弹出密码提示。
- 后端新增邮件已读标记表与接口，使用账号类型、邮箱账号、文件夹和消息 ID 持久保存已读状态。
- Cloud Mail 与微软邮箱列表读取邮件时合并服务端已读标记，点击邮件后立即写入已读标记，避免刷新后又恢复未读。
- 部署文档补充镜像检查的稳健流程，避免本机缺少 Docker 时进入无效长时间轮询。
