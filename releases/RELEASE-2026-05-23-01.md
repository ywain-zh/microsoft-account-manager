## 本次更新内容摘要
- 新增 `account_aliases` 表，记录别名邮箱到主邮箱账号的本地映射，主邮箱删除时级联删除别名。
- 新增别名查询和创建接口：`GET /api/accounts/:id/aliases`、`POST /api/accounts/:id/aliases`。
- 微软邮箱列表返回主邮箱行和别名投影行；搜索关键词可匹配主邮箱、备注和别名。
- 邮件开放接口支持通过主邮箱或别名解析到同一主邮箱取信，并返回 `requestedEmail`、`resolvedAccount`、`matchedAlias` 元数据。
- 前端微软邮箱列表新增“新建别名邮箱”图标按钮；弹框支持随机生成 `<6位随机小写字母数字>-<主邮箱前缀>@<主邮箱域名>` 并连续创建。
- 别名行来源显示“别名邮箱”，密码显示“继承主邮箱”，不支持编辑、删除、刷新 RF、密码编辑或继续创建别名。
- GPT JSON 导出按当前行邮箱传参；GPT 有效检测仅保留主邮箱行检测。

## 风险说明
- 本次别名是系统内本地映射，不会自动在 Microsoft 官方账号中创建 Outlook.com alias；如需真实收到发往别名的邮件，Microsoft 侧必须已有官方 alias 或外部转发。
- 上线后会新增数据库表，部署前需要备份线上 SQLite 数据库。
- 别名行复用主邮箱 refresh token 取信；如果主邮箱 token 失效，别名行同样无法取信。
