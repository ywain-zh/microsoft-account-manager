## 本次更新内容摘要
- 在共用邮件详情组件中识别非中文邮件正文，并显示“翻译成中文”入口。
- 翻译成功后支持查看中文译文和切回原文。
- 后端新增翻译配置、OpenAI 模型列表、翻译测试和翻译执行接口。
- 翻译调用优先使用 OpenAI 兼容接口，失败后自动 fallback 到 DeepLX。
- 左侧菜单新增 `系统设置`，位于 `Sub2API 检测` 下方，提供翻译配置、保存、测试和模型刷新功能。
- API Key 不写入源码，只通过系统设置保存到后端配置。
