## 本次更新内容摘要
- 公益站签到网络请求改用 `undici` + `ProxyAgent`，统一直连和代理请求处理，避免自研 HTTP 解析遗漏 gzip/br/deflate、CONNECT、chunked 等协议细节。
- 防护页处理支持多次重试、合并 `Set-Cookie`、重新计算 `acw_sc__v2`。
- 增加 Any Router 运行时识别与专用 Cookie Header 策略。
- 修复通用 NewAPI 请求中重复发送 `New-Api-User` / `New-API-User` 导致服务端收到 `4203, 4203` 的问题。
- 系统设置代理页将“重新载入”改为“测试系统代理”，新增后端测试接口，使用当前输入框代理地址检测出口 IP 和节点。
- 公益站账号列表和全量签到固定按账号添加时间排序，检测、刷新余额、签到不会改变行顺序。
- 补充公益站相关单元测试覆盖 JSON 错误 message、Any Router Header、Set-Cookie 合并、NewAPI Header 去重等场景。
