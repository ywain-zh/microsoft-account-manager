## 本次更新内容摘要
- Stripe 支付页面新增“代理配置”区域，可保存启用状态、协议、host、port、用户名和密码。
- 支持粘贴 `host:port:user:pass` 格式并自动解析，协议可选 `HTTPS` 或 `socket5 / SOCKS5`。
- 新增代理测试接口，后端通过 `pay.py --test-proxy` 使用真实 Python requests 代理逻辑验证出口连通性。
- 支付运行时自动读取已保存代理配置；临时配置模式和服务器默认配置模式都会写入本次运行临时 config，不修改持久 `config.json`。
- `pay.py` 支持 `proxy.protocol`，HTTPS 使用 `https://`，SOCKS5 使用 `socks5h://`，并对代理账号密码做 URL 编码。
- 日志只显示代理协议、host 和 port，不输出代理用户名和密码；后端返回日志继续脱敏。
- Docker 运行镜像增加 `py3-pysocks`，支持 Python requests 的 SOCKS5 代理。
