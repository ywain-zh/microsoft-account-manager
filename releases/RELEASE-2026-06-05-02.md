## 本次更新内容摘要
- hosted checkout 返回缺少 `openai_payurl` 时，根据 `checkout_session_id` 合成 `https://pay.openai.com/c/pay/{session_id}?ui_mode=hosted`。
- Python helper 在返回中保留本次 `checkout_ui_mode`，避免 custom 模式和 hosted 模式展示混淆。
- TS API 归一化层增加同样兜底，确保页面优先复制/打开 OpenAI Pay 长链。
- 增加单测覆盖上游只返回 `chatgpt.com/checkout/openai_llc/cs_live...` 的场景。
