## 本次更新内容摘要
- 新增 Cloud Mail 分享记录表，URL 使用随机 token，数据库只保存 token hash。
- 新增登录态分享管理接口：创建/获取分享、重新生成分享、关闭分享。
- 新增免登录公开接口：通过分享 token 只读读取对应 Cloud Mail 收件箱。
- Cloud Mail 列表新增“分享”入口，弹窗支持复制链接、重新生成和关闭分享。
- 新增 `/share/cloud-mail/:token` 公开只读收件箱页面，不进入后台登录守卫，不写入已读状态。

## 风险说明
- 分享链接属于 bearer token，拿到链接的人可只读查看对应邮箱收件箱；需要通过“关闭分享”或“重新生成”收回旧链接。
- 新公开收件箱接口会访问上游 Cloud Mail 邮件接口；上游配置失效或网络异常时，公开页会显示读取失败。
- 新增数据库迁移会在容器启动时自动执行，应重点观察启动日志和健康检查。
