## 本次发布目的
- 将后台信息架构收敛为 Cloud Mail 与微软邮箱两张核心列表页，去掉接口管理与多余一级入口。
- 按设计稿与设计规范重构两张邮箱列表页，并修正工具栏按钮、表格与 Cloud Mail 配置区的视觉细节，使现网页面与设计稿一致。

## 本次更新内容摘要
- 重新整理后台导航与路由，仅保留 Cloud Mail 与微软邮箱两个页面，并默认进入 Cloud Mail。
- 微软邮箱列表页按设计稿重构页面头部、工具栏、表格与分页，保留原有业务逻辑、批量操作、导入和收件箱查看能力。
- Cloud Mail 列表页按设计规范重构工具栏、配置摘要、异常提示、表格与分页，保留配置、新增、删除与收件箱查看逻辑。
- 收紧两张列表页的页面级按钮样式 token，移除对全局 toolbar 按钮视觉的依赖，修正按钮颜色层级、hover 态、图标尺寸与描边细节。
- 延续上一轮收件箱弹窗改版结果，继续复用统一的邮件预览与状态展示能力。
