## 本次更新内容摘要
- 新增每日余额基线表，按 `account_id + local_date` 保存每天 0 点采集到的余额。
- 新增公益站每日 0 点余额基线调度，时区沿用 `public_checkin_settings.timezone`。
- 账号列表接口新增 `dailyBalanceDisplayMode` 和 `dailyBalanceDisplayAmount`，不再依赖历史 `lastCheckinReward` 展示余额第二行。
- 列表余额第二行根据当天基线、今日签到奖励总和、当前余额计算：
  - 缺少有效基线时隐藏。
  - 签到成功后优先显示 `+奖励`。
  - 后续余额刷新计算出今日已用 `> 0` 时显示 `-已用`。
- 前端余额单元格只展示带符号金额，通过 `title` 区分“今日签到奖励”和“今日已用”。
- 补充后端测试覆盖基线缺失、跨天重置、签到优先、后续消耗切换、手动刷新不补基线、0 点基线采集等场景。

## 风险说明
- 本次上线后，当天如果没有 0 点基线，余额第二行会按设计隐藏，到下一次 0 点基线成功采集后再开始显示。
- 0 点基线采集会对每个启用账号执行一次余额拉取，需观察公益站接口稳定性。
- 如果部署后立即验证今日已用展示，可能需要等待下一次 0 点基线，或确认数据库中已有当天基线。
