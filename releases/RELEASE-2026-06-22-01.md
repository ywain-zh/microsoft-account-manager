## 本次更新内容摘要
- 公益站签到成功后，运行时结果会携带签到前余额、签到后余额和用于通知的今日新增额度。
- Telegram 签到汇总新增成功明细，并使用 HTML `<blockquote expandable>` 默认折叠。
- 成功明细固定展示为 `站点：总额度 x，今日新增 +y`，余额或奖励缺失时使用 `-` 占位。
- 今日新增优先使用签到奖励；奖励缺失时使用签到前后余额差推算。
- 失败/跳过明细继续保持在折叠块外可见。
- Telegram 发送层增加 `parse_mode=HTML`，并对站点名、账号名和异常信息做 HTML 转义。
- 成功明细过长时保留闭合 HTML 折叠块，并提示剩余未展示条数，避免消息被截断成无效 HTML。
- 保留上一版通知时间按公益站 timezone 渲染的行为。

## 风险说明
- Telegram HTML 折叠依赖客户端对 `<blockquote expandable>` 的支持；不支持的客户端仍会看到明细文本。
- 成功明细的总额度依赖签到后余额刷新结果；刷新失败时会显示 `-`，不会影响签到结果和异常明细。
- 本次只改运行时结果传递和通知渲染，不改数据库结构。
