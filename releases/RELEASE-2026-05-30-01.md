## 本次更新内容摘要
- 新增本项目内置的 SUB2API OAuth runtime，实现生成 OpenAI OAuth URL、解析 localhost callback、校验 state、exchange-code、构建 OpenAI OAuth 账号 payload、分组和代理解析、远端错误脱敏。
- `browser-login` 自动重新授权流程改为：点击登录 -> 输入邮箱 -> 获取验证码 -> 刷新 OAuth并登录 -> 自动确认 OAuth -> SUB2API 回调验证。
- 验证码登录成功后不再读取 ChatGPT session 并导入，而是打开 SUB2API 生成的 OAuth URL，自动确认授权页并捕获 localhost callback。
- `session-json` 和 `access-token` 模式继续保留旧的 session 导入逻辑。
- 前端重新授权弹窗文案更新为六步流，自动登录模式下只保留回调验证后复测选项。
- 日志按六步输出详细进度，并对 callback code、access token、refresh token 等敏感值脱敏。

## 风险说明
- 自动浏览器 OAuth 授权依赖 OpenAI 授权页按钮文本和 localhost callback URL，若 OpenAI 页面结构或回调路径变化，可能导致步骤 5 超时。
- Sub2API 实例需要支持 `generate-auth-url` 和 `exchange-code` 接口，否则步骤 4 或步骤 6 会返回明确远端错误。
- 线上 2C2G 小机器仍应一次只运行一个浏览器重新授权任务，避免 Chromium 占用过高。
- 如果 OAuth state 不一致，流程会在提交远端 exchange-code 前失败并提示重新执行授权。
