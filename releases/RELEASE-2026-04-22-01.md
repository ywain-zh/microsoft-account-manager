## 本次更新内容摘要
- Cloud Mail 列表移除“收件数 / 发件数 / 最近活跃时间”三列，新增“备注”列。
- Cloud Mail 列表每行备注区域新增编辑图标，点击后可打开弹窗编辑备注。
- 前端状态层新增备注弹窗、备注表单与保存逻辑，保存成功后直接局部更新当前行。
- 后端新增 Cloud Mail 备注更新接口，并在 Cloud Mail 列表返回项中合并本地备注数据。
- 新增 `cloud_mail_account_remarks` 迁移表，用于在不修改远端 Cloud Mail 服务结构的前提下持久化备注。
- 删除 Cloud Mail 邮箱时会同步清理本地备注记录，避免残留脏数据。
