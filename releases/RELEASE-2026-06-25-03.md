## 本次更新内容摘要
- 系统设置 -> 接口鉴权页新增 YesCaptcha `clientKey` 明文输入框。
- 新增 `/api/system/yescaptcha-config` 读取和保存接口，配置保存到 `app_settings`。
- 公益站签到运行时优先读取系统设置中的 YesCaptcha `clientKey`，未配置时继续回退 `YESCAPTCHA_CLIENT_KEY` / `YES_CAPTCHA_CLIENT_KEY` 环境变量。
- Ciallo 返回 Turnstile token 缺失时，会读取站点 `/api/status` 的 `turnstile_site_key`，通过 YesCaptcha 获取 token 后重试签到。
- 补充 YesCaptcha 配置读写和路由测试。

## 本次是否涉及配置变更
- 是。不再强制要求线上 `.env` 新增 `YESCAPTCHA_CLIENT_KEY`。
- 线上部署后需要登录管理台，在“系统设置 -> 接口鉴权 -> YesCaptcha”中填写 `clientKey`。
- 可选环境变量仍可保留：
  - `YESCAPTCHA_CLIENT_KEY`

## 风险说明
- YesCaptcha `clientKey` 按用户要求在系统设置页明文显示，并以普通系统配置保存。
- Ciallo 每次需要 Turnstile 的签到会消耗 YesCaptcha 余额。
- 如果 YesCaptcha 余额不足、接口异常或站点变更 Turnstile 参数，Ciallo 签到仍会失败并写入错误日志。
