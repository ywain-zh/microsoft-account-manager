## 本次发布目的

- 同步保留 query 回跳兜底，避免 popup 被拦截或 opener 不可用时登录流程失效。

## 本次更新内容摘要
- 将 Microsoft OAuth authorize 与 token 入口统一为 `common`，避免个人账号授权和换 token 使用不同租户入口。
- 扩展 OAuth state，记录 popup / redirect 模式，并在 callback 侧按模式输出 popup HTML 回传或原有 query redirect。
- 前端微软邮箱页改为 popup 优先发起 OAuth，授权结果通过 `postMessage` 回传并刷新列表；popup 不可用时退回原有整页跳转。
- 保留现有 `/services/microsoft-mail/accounts?oauth=...` query 消费逻辑作为兼容兜底。
- 将本地默认管理员密码示例值更新为 `admin123`。
