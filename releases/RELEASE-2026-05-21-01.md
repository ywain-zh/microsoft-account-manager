## 本次更新内容摘要
- 导出接口继续先通过 Sub2API 管理接口按邮箱搜索并确认账号匹配。
- 当管理接口返回的账号记录不包含 `id_token`、`access_token`、`refresh_token` 时，后端按账号 ID 通过服务器内 Docker 访问 `sub2api-postgres`，只读查询 `public.accounts.credentials` 生成 GPT JSON。
- 数据库查询按 Sub2API 账号主键 `id` 定位，并再次校验邮箱匹配，避免跨账号导出。

## 风险说明
- 导出路径会在 Sub2API 管理接口不返回 token 时读取 `sub2api-postgres` 容器；如果服务器 Docker socket 或 `sub2api-postgres` 不可用，导出会返回错误，但不会影响账号列表、检测或邮件功能。
- 导出内容包含敏感 token；接口仍保持登录态保护，验证过程不在日志或聊天中输出 token 内容。
