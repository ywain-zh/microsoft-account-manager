# Release 2026.05.16-2

## 基本信息

- 发布日期：2026-05-16
- 来源分支：`dev`
- 镜像版本：`ghcr.io/ywain-zh/microsoft-account-manager:2026.05.16-2`
- 回滚版本：`ghcr.io/ywain-zh/microsoft-account-manager:2026.05.16-1`

## 发布目的

在微软邮箱账号列表中增加 GPT 有效检测入口，位置在“邮箱状态”右侧，复用现有 Sub2API GPT 有效性检测接口。

## 修改文件

- `src/state/admin-console.ts`
- `src/views/AccountsView.vue`
- `src/utils/datetime.ts`
- `releases/RELEASE-2026-05-16-02.md`

## 更新内容

- 微软邮箱账号状态中新增按邮箱记录的 GPT 检测加载状态和检测结果。
- 微软邮箱表格在“邮箱状态”右侧新增“GPT有效”列。
- 未检测时显示“检测”按钮，点击后通过 Sub2API 检测当前邮箱 GPT 是否有效。
- 检测有效时显示绿色“GPT有效”，并支持再次点击重新检测。
- 检测无效时不显示无效文案，仅保留空白占位。
- 补齐当前管理台依赖的北京时间格式化工具文件，保证 CI 和镜像构建可复现。

## 部署步骤

1. 提交本次变更到 `dev`。
2. 推送 `dev`。
3. 创建并推送 tag `2026.05.16-2`。
4. 等待 GitHub Actions 构建并发布 GHCR 固定 tag 镜像。
5. 在阿里云服务器 `/opt/microsoft-account-manager` 备份 `.env` 和 SQLite 数据库。
6. 将 `.env` 中 `APP_IMAGE` 更新为 `ghcr.io/ywain-zh/microsoft-account-manager:2026.05.16-2`。
7. 执行 `docker compose pull` 和 `docker compose up -d`。
8. 检查容器状态、日志、资源占用和健康接口。

## 回滚方式

如需回滚，切回上一版已验证镜像：

```bash
cd /opt/microsoft-account-manager
sed -i "s#^APP_IMAGE=.*#APP_IMAGE=ghcr.io/ywain-zh/microsoft-account-manager:2026.05.16-1#" .env
docker compose pull
docker compose up -d
docker compose exec -T microsoft-account-manager wget -qO- http://127.0.0.1:8787/api/health
```
