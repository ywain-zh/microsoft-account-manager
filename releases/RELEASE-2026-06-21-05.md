## 本次更新内容摘要
- 全局 `SecretInput` 固定使用明文输入，移除密码圆点、眼睛按钮和隐藏/显示状态。
- 登录页密码框改为明文输入，登录成功后仍清空表单密码值。
- 公益站添加/编辑账号弹窗增加隐藏 autofill guard，降低浏览器把登录账号密码自动填入站点 URL、User ID 等业务字段的概率。
- 公益站账号表单为站点名称、站点 URL、Key、User ID、模型 API Key 设置独立 `name` 和 `autocomplete` 属性。
