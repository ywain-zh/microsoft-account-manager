## 本次更新内容摘要
- 新增 Cloud Mail 账号缓存表，按当前 Cloud Mail 配置隔离缓存。
- `GET /api/cloud-mail/accounts` 改为优先读取数据库缓存，保留原有分页、搜索与备注展示结构。
- 新增 `POST /api/cloud-mail/accounts/sync`，用于从远端同步账号并写入本地数据库缓存。
- Cloud Mail 页面进入时先显示本地缓存，再后台静默同步；手动刷新改为显式远端同步，表格不再整页发白等待远端。
- 新增、删除、备注保存后同步维护 Cloud Mail 本地缓存。
- 微软邮箱密码列支持手动输入保存并提供复制按钮，同时优化列宽分配。
- 修复 OAuth 登录完成后按钮持续 loading 且列表不自动刷新的问题。
- 为备注编辑表单与密码输入增加非凭据 autocomplete 标记，减少 Chrome 误弹保存密码提示。

## 风险说明
- 首次无缓存时仍依赖 Cloud Mail 远端接口完成首次同步。
- 远端同步失败时会保留旧缓存，页面不清空，但数据可能短时间不是最新。
- 新增 SQLite 表为加法迁移，主要风险在迁移执行与远端账号字段兼容性。
