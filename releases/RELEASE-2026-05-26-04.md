# Release 2026.05.26-4

## Image

- `ghcr.io/ywain-zh/microsoft-account-manager:2026.05.26-4`

## Scope

- Remove the long-link generator local proxy mode and related UI.
- Keep the network proxy pool as the only configurable proxy source for long-link generation and proxy testing.
- Keep the empty-pool behavior: requests use the server machine egress when no network proxy is configured.
- Keep saved proxy nodes hidden from the textarea after reload; saved nodes are shown only in the proxy list.

## Config

- Update only `APP_IMAGE` in `.env` during deployment.
- Existing saved long-link local proxy fields are ignored by the new config normalizer.
- No database migration is required.

## Validation

- `npm run typecheck`
- `npm run build`

## Deploy

- Follow `DEPLOY_LITE.md`.
- Do not run `npm install`, `npm run build`, `docker build`, or `docker compose up --build` on the server.

## Rollback

- Set `APP_IMAGE=ghcr.io/ywain-zh/microsoft-account-manager:2026.05.26-3`
- Run `docker compose pull && docker compose up -d`
