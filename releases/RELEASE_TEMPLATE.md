# RELEASE 模板

## 本次发布日期
- YYYY-MM-DD

## 本次发布版本/tag
- `ghcr.io/ywain-zh/microsoft-account-manager:YYYY.MM.DD-N`

## 本次发布目的
- 说明本次发布要解决什么问题。

## 本次来源分支
- 默认填写：`dev`
- 如本次发布前存在临时分支合并，补充说明即可。

## 本次集成分支
- 固定填写：`dev`

## 本次是否涉及上游同步
- 是 / 否
- 如为“是”，说明是否包含 `upstream/main -> main -> dev` 的同步。

## 本次是否涉及冲突处理
- 是 / 否
- 如为“是”，说明冲突来源、冲突文件和处理结论。

## 本次修改文件列表
- 列出本次涉及的关键文件。

## 本次更新内容摘要
- 用简洁条目说明本次改动。

## 本次是否涉及配置变更
- 是 / 否
- 如为“是”，说明需要更新哪些环境变量、镜像 tag、部署参数。

## 本次是否涉及数据结构/迁移
- 是 / 否
- 如为“是”，说明迁移内容、风险和回滚方式。

## 本次部署步骤
- 必须引用 `DEPLOY_LITE.md` 中的标准步骤，不允许另发明流程。
- 发布来源必须是 `dev`。

## 本次验证范围
- 例如：`npm run typecheck`
- 例如：`npm run build`
- 例如：关键页面 / 关键接口冒烟结果

## 本次回滚方式
- 说明切回哪个已验证 tag，以及是否需要恢复数据库备份。

## 风险说明
- 说明本次发布的主要风险点和观察项。

## 审核状态
- 待审核 / 审核通过

## 部署状态
- 未部署 / 已部署 / 已回滚
