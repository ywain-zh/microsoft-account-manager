## 本次更新内容摘要
- 新增全局渐变设计系统，统一按钮、列表面板、弹窗、表格、顶部栏、侧边栏和卡片视觉。
- 调整后台顶部栏为单一页面标题区，移除页面内重复标题，保留左侧菜单结构。
- Cloud Mail、微软邮箱、Sub2API 检测、系统设置等页面接入统一列表面板与渐变组件风格。
- 邮件详情弹窗调整左右比例，修复收件箱列表和正文区域滚动体验。
- 邮件详情只保留必要元信息，发件人和时间改为更紧凑的两行展示。
- 邮件列表预览提取可读正文，避免展示原始 HTML 片段。
- 优化邮件翻译展示，减少翻译后丢失原 HTML 布局的影响。
- 系统设置翻译配置改为更紧凑布局，去除默认填充的接口文案，新增翻译优先级配置。
