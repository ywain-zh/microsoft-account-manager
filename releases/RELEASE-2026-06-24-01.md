## 本次更新内容摘要
- 公益站账号列表新增“公告”入口，并展示每个站点的未读公告数量。
- 后端新增公益站公告拉取、按站点入库、已读标记、未读统计和定时轮询能力。
- 公告弹窗改为多条卡片流，默认首条展开，其他公告默认折叠，可单独展开或收起。
- 公告正文新增轻量 Markdown 渲染，支持常见行内代码和 fenced code block，包括单行三反引号写法。
- 公告正文代码块以安全转义文本方式展示，并继续经过 DOMPurify 净化。
- 新公告首次发现时可复用现有 Telegram 通知链路发送提醒；重复同步只更新本地记录。
