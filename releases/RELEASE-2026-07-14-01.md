## 本次更新内容摘要
- 删除 Sub2API 检测页的导航入口、路由、页面组件和前端状态模块。
- 移除微软账号与 Cloud Mail 账号页的 GPT 有效状态列、套餐筛选、检测按钮和 GPT JSON 导出入口。
- 移除前端相关 API、类型与状态，账号列表请求不再发送 `gptPlan`。
- 后端账号列表不再关联或返回 `mail_gpt_validity_status` 数据。
- 已下线的 Sub2API 检测、GPT 有效检测和 GPT JSON 导出接口统一返回 HTTP `410`；历史辅助实现和说明注释保留，便于后续追溯。
- 保留并发布现有的错误链详情增强，使底层 `cause` 错误码和消息可出现在服务端错误信息中。

## 风险说明
- 原 Sub2API 检测及 GPT 有效检测/导出接口会从可用状态变为 HTTP `410`，仍依赖这些接口的外部调用方需要同步停止调用。
- 账号列表响应不再包含 GPT 有效状态字段，依赖旧字段的外部消费者需要同步调整。
- 本次删除较多前端代码，上线后需确认后台导航、微软账号页和 Cloud Mail 账号页可正常加载与操作。
- 错误链详情增强可能让错误提示包含更具体的底层网络错误信息，需要观察线上提示长度和可读性。
