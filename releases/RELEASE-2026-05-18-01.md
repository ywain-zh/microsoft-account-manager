## 本次更新内容摘要
- 系统设置页新增“备份”标签，展示备份进度、日志、文件大小、SHA256，并提供下载和清理临时文件按钮。
- 新增后端备份任务接口，支持创建任务、查询任务、下载备份包和清理服务器临时文件。
- 当前项目 SQLite 使用 `VACUUM INTO` 生成在线一致副本。
- Sub2API PostgreSQL 使用 `pg_dumpall` 在线导出，Redis 使用 `redis-cli SAVE` 生成快照。
- 备份包包含项目配置、`.env`、compose 文件、nginx/cron 配置和恢复说明。

## 本次是否涉及配置变更
- 是
- Docker 镜像新增 `docker-cli`。
- `docker-compose.yml` 新增 Docker socket 和宿主机只读目录挂载，用于在线备份访问 Docker 容器和项目配置：
  - `/var/run/docker.sock:/var/run/docker.sock`
  - `/opt:/host/opt:ro`
  - `/root:/host/root:ro`
  - `/etc/nginx:/host/etc/nginx:ro`
  - `/etc/cron.d:/host/etc/cron.d:ro`
  - `/var/spool/cron:/host/var/spool/cron:ro`

## 风险说明
- 备份功能依赖容器内 Docker CLI、Docker socket 挂载以及宿主机只读目录挂载；如果挂载缺失，页面会显示备份失败日志。
- Docker socket 挂载提升了容器操作 Docker 的能力，需要继续限制系统设置页访问在管理员登录态内。
- 备份期间主项目不会停止，但 Sub2API 的在线 dump 可能带来短时 IO/CPU 开销。
