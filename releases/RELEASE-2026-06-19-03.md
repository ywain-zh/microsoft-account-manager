## 本次更新内容摘要
- 新增系统通知配置接口，支持 Telegram Bot Token 加密保存、脱敏读取和测试发送。
- 系统设置页新增“通知”tab，可配置 Telegram 开关、Bot Token、Chat ID、系统代理复用，并可发送测试通知。
- 公益站每日定时签到完成后发送一条 Telegram 汇总；手动签到不通知。
- 定时签到异常时发送异常通知；通知失败只记录日志，不影响签到任务。
- 新增通知配置、汇总消息和截断逻辑单测。

## 本次是否涉及配置变更
- 是。
- 新增可选环境变量 `NOTIFICATION_ENCRYPTION_KEY`，格式为 32 字节 hex 字符串；不填写时会在数据目录自动生成 `notification-encryption.key`。
- Telegram Bot Token 和 Chat ID 通过“系统设置 -> 通知”保存，不需要写入 `.env`。

## 风险说明
- Telegram 通知依赖服务器访问 `https://api.telegram.org`；如直连不可用，需要在系统设置中配置代理并开启复用系统代理。
- Telegram Bot Token 已在对话中短暂暴露，部署后建议通过 `@BotFather` 轮换 token 并在系统设置中保存新 token。
- 定时签到汇总只在 scheduler 触发时发送，手动签到不会发送通知。
