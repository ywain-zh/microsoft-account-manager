# Release 2026.05.26-6

## Image

- `ghcr.io/ywain-zh/microsoft-account-manager:2026.05.26-6`

## Scope

- Fix long-link generator token extraction for exported GPT JSON arrays such as `[{"access_token":"..."}]`.
- Keep support for raw JWT tokens, single JSON objects, nested `data.accessToken`, and regex fallback extraction.
- Return readable long-link checkout errors instead of `[object Object]` or generic internal server errors.

## Config

- Update only `APP_IMAGE` in `.env` during deployment.
- No database migration is required.
- Do not log or persist pasted token values.

## Validation

- `npm run typecheck`
- `npm run build`

## Deploy

- Follow `DEPLOY_LITE.md`.
- Use short, separate server commands for pull, up, and health checks.
- Do not run `npm install`, `npm run build`, `docker build`, or `docker compose up --build` on the server.

## Rollback

- Set `APP_IMAGE=ghcr.io/ywain-zh/microsoft-account-manager:2026.05.26-5`
- Run `docker compose pull && docker compose up -d`
