## 本次更新内容摘要
- 新增 Sub2API 分组列表接口，目标分组改为从远端同步后下拉选择。
- 配置弹框移除鉴权模式选择，重新授权固定使用管理员 API Key。
- 配置弹框底部合并为一个“保存配置”按钮，保存连接配置和重新授权配置。
- 连接配置打开时自动同步一次分组，并记录同步状态。
- ChatGPT 验证码未命中后的邮箱轮询间隔从 5 秒缩短为 2 秒。

- 验证码轮询频率提高到 2 秒，验证码未到达时邮箱接口请求次数会增加。
- 自动登录仍依赖 ChatGPT 页面、验证码邮件和人机验证策略。
