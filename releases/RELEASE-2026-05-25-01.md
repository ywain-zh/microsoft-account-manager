## 本次更新内容摘要
- 新增 `/services/sub2api/long-link-generator` 页面和导航项“长链生成器”。
- 新增长链生成器后端接口：配置读写、真实代理检测、checkout 长链生成。
- 代理池支持 `host:port:user:pass`、`http(s)://user:pass@host:port`、`socks5/socks5h` 等格式。
- 辣椒代理格式会自动规范化为 HTTP 认证代理；代理池为空时默认走服务器本机出口。
- 生成 checkout 时按代理池顺序尝试，成功返回 `pay.openai.com` 长链和实际使用出口。
- 后端错误信息对 accessToken 和代理密码做脱敏处理。

## 风险说明
- 长链生成依赖 ChatGPT checkout 接口、accessToken 有效性和代理出口可用性；远端策略变化可能导致 checkout 失败。
- 代理检测依赖外部 IP 查询服务；单个查询服务失败时会自动尝试其他服务。
- SOCKS5 代理由 Playwright 请求上下文处理，个别代理服务可能只支持 HTTP 认证代理。
