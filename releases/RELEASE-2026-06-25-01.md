## 本次更新内容摘要
- 余额刷新成功时，如果当天基线缺失，自动按“当前余额 - 当天已成功签到奖励总和”补一条恢复基线。
- 恢复基线只在缺失时写入，不覆盖 0 点定时采集到的正式基线。
- 保持 0 点基线采集使用原有覆盖更新逻辑，避免影响跨天基线刷新。
- 补充缺失基线恢复、早于恢复的当天奖励、已有基线不覆盖等后端测试。

## 风险说明
- 如果账号当天没有 0 点基线，第一次成功余额刷新会以刷新时的余额作为恢复点；刷新之前已经发生但系统无法观测到的消费不会被追溯。
- 如果当天签到奖励已记入日志，恢复基线会扣除当天奖励总和，后续再次消费后可正常切换为“今日已用”。
- 已存在 0 点正式基线的账号不受恢复逻辑覆盖影响。
