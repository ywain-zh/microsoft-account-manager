## 本次更新内容摘要
- 长链生成器代理配置新增 `proxyMode`、`localProxyRegion`、`localProxy`，旧配置会自动补默认值。
- 代理配置弹框新增“总配置”和“本地代理”区域，JP 默认 `127.0.0.1:7892`，US 默认 `127.0.0.1:7893`。
- 本地代理支持 `http`、`https`、`socks5`、`socks5h` 协议，并提供 JP/US 单独真实 IP 检测。
- 长链生成和默认代理检测按当前选择的本地代理或网络代理池执行，不混用。
- 网络代理池继续保留导入、测试全部、删除、保存和节点列表展示；保存或重新载入后 textarea 保持为空。
- GHCR workflow 改为直接执行 `docker login`、`docker build`、`docker push`。

## 风险说明
- 本地代理模式依赖服务器容器访问对应本地代理地址；如容器内无法访问 `127.0.0.1:7892/7893`，需要改为容器可达的代理地址。
- 网络代理池旧配置会继续保留，切换到本地代理时不会参与长链生成。
- 新 GHCR workflow 依赖 GitHub hosted runner 自带 Docker 能力；若 runner 环境异常，需要查看 workflow 日志后处理。
