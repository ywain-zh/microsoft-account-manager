## 本次更新内容摘要
- 新增侧边栏菜单 `Stripe支付`，路由为 `/services/stripe/payment`。
- 新增 Stripe 支付执行页面，支持输入 Checkout Session/URL、卡索引、配置档案和可选 hCaptcha Token。
- 新增前端 API 类型与 `runStripePayment` 请求方法。
- 新增受保护后端接口 `POST /api/stripe-payment/run`，通过 Node 子进程受控调用 `pay.py`。
- 后端执行脚本时使用参数数组和 `shell: false`，并增加单任务锁、超时、输出截断和基础日志脱敏。
- 配置文件路径不由前端任意传入，首版仅允许后端预设 `default -> config.json`。

## 本次是否涉及配置变更
- 是
- 服务器镜像需更新到固定 tag：`ghcr.io/ywain-zh/microsoft-account-manager:2026.04.25-5`。
- 如运行环境的 Python 命令不是 `python`，可设置 `PAY_PYTHON_BIN`。
- 如 `pay.py` 或 `config.json` 不在默认项目根路径，可设置 `PAY_SCRIPT_PATH` 或 `PAY_CONFIG_DEFAULT_PATH`。
- 可通过 `PAY_TIMEOUT_MS` 调整脚本执行超时，默认 120000ms。
- 支付脚本运行仍依赖服务器镜像/环境内可用的 Python 依赖和 `config.json` 配置。
