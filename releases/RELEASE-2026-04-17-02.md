# RELEASE-2026-04-17-02

## 本次发布日期
- 2026-04-17

## 本次发布版本/tag
- `ghcr.io/ywain-zh/microsoft-account-manager:2026.04.17-2`

## 本次发布目的
- 修复微软邮箱收件箱中“已读邮件仍显示未读”的问题，避免用户打开邮件后状态与实际阅读情况不一致。
- 同步统一 Cloud Mail 收件箱的本地已读交互，保持两套收件箱体验一致。

## 本次修改文件列表
- `server/app.ts`
- `src/state/admin-console.ts`
- `src/state/cloud-mail-console.ts`
- `src/views/AccountsView.vue`
- `src/views/CloudMailAccountsView.vue`
- `releases/RELEASE-2026-04-17-02.md`

## 本次更新内容摘要
- 放宽微软邮件读状态解析规则，兼容 `true/false`、`1/0`、`read/unread`、`seen/new` 等返回值，避免服务端把已读状态漏判为空。
- 微软邮箱收件箱在用户点击邮件后，会立即把当前邮件本地状态切换为已读，避免界面继续显示“未读”。
- Cloud Mail 收件箱同步补上相同的本地已读切换逻辑，保持收件箱交互一致。
- 不调整邮件拉取接口、页面结构或其他业务逻辑，仅修正已读/未读状态映射与展示同步。
