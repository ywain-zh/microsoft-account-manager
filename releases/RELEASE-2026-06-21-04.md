## 本次更新内容摘要
- 公益站日志弹框改为更紧凑的展示，减少横向溢出和重复占位。
- 公益站自动签到状态改为只读展示：开启为绿色，关闭为灰色，不再允许在列表页直接关闭。
- 全局 `SecretInput` 隐藏态改为原生密码圆点，并保留右侧显示/隐藏按钮，替换原来的灰色分段遮罩。
- 系统通知配置里的 Telegram Bot Token 支持回显到输入框，默认隐藏，点击眼睛按钮后可查看。
- 后端通知配置接口返回已保存的 Bot Token 解密值，仍由前端密钥输入框默认隐藏展示。
- 更新通知配置测试，覆盖保存、读取、保留和清空 Token 的行为。
