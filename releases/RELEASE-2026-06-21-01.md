## 本次更新内容摘要
- 公益站账号新增账号级 API Key 存储，用于读取 OpenAI 兼容模型列表。
- 公益站添加/编辑弹窗支持配置 API Key；未配置时点击模型会提示先配置。
- 公益站模型弹框改为只展示模型，不再做逐模型测速。
- 公益站模型列表按厂商优先级排序：`gpt-*`、`claude-*`、`gemini-*`、`deepseek-*`、其它。
- Sub2API 配置新增持久化目标分组，导入时按保存的分组解析远端 `group_id`。
- Sub2API 检测页新增 `导入 API-SUB2API` 按钮和导入弹窗。
- 导入弹窗支持粘贴 `.env`、JSON、curl/Header 和混合文本，自动解析 `Base URL + API Key` 并实时预览。
- 后端新增 `POST /api/sub2api/accounts/import-apikey`，按 `OpenAI + API Key` 类型批量创建账号。
- 导入时会按远端账号列表做重复检测，命中重复时返回“已存在并跳过”，单条失败不影响其它条。
- 修正导入前目标分组提示逻辑：已选择但未保存时提示先保存配置，避免误报未选择分组。

## 风险说明
- 公益站 API Key 使用现有敏感凭证加密模式保存；如果未配置 API Key，模型按钮只提示配置，不会发起模型请求。
- Sub2API 导入依赖远端账号列表返回的字段；如果远端不返回明文 API Key，会退化为同分组、同名、同 Base URL 的疑似重复判断。
- 导入创建使用固定默认参数：`proxy_id=null`、`concurrency=10`、`priority=1`、`rate_multiplier=1`。
- 导入只支持 `openai + apikey` 类型，不覆盖 OAuth、Gemini、Anthropic、Antigravity 或 Bedrock 账号。
